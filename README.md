# 보안길잡이 AI 프로토타입

공공기관 현업 담당자가 AI와 대화하며 방화벽 신청서를 작성하고, ICT인프라·정보보안 담당자가 함께 검토하는 흐름을 보여주는 시연용 프로토타입입니다. 2026 공공 AI 대전환 챌린지 출품을 위해 만들었습니다.

> 모든 데이터는 합성 데이터이며 AI 응답은 미리 정한 시나리오입니다. 실제 파일 전송, 저장, 알림, 기관 전송은 일어나지 않습니다.

## 시연 주소

GitHub Pages를 켜면 아래 주소에서 열립니다.

https://team-khfc.github.io/prototype-soo/

## 시연 방법

1. 오른쪽 위 사용자 이름 옆 화살표를 눌러 다른 사용자로 바꾸면 역할별 화면을 볼 수 있습니다.
   - 김민지 (주택연금부, 신청자)
   - 박준호 (정보인프라팀, ICT인프라 담당)
   - 이서연 (정보보호팀, 정보보안 담당)
   - 정해원 (디지털혁신실, 기관 관리자)
2. 신청자로 **새 신청**에서 기획서를 올리거나 대화로 답하면 방화벽 규칙 초안이 만들어집니다.
3. ICT인프라 담당으로 바꿔 서버 주소·포트를 입력하고, 정보보안 담당으로 바꿔 검토합니다.
4. 다시 신청자로 바꿔 최종 제출하고, 정보보안 담당이 처리 결과를 기록하면 **정책 수명주기**에 등록됩니다.

왼쪽 메뉴 오른쪽 위의 손잡이(‹)로 메뉴를 접고 펼 수 있고, 상단의 작은·큰 “가” 버튼으로 글자 크기를 바꿀 수 있습니다. Ctrl+K를 누르면 신청·화면 검색창으로 이동합니다.

데이터는 브라우저 메모리에만 있어 새로고침하면 처음 상태로 돌아갑니다. 글자 크기, 메뉴 접힘, 대화창 너비 설정만 브라우저에 저장됩니다.
